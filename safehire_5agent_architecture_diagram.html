SAFEHIRE ARCHITECTURE

5-Agent Autonomous AI Sequential Workflow

Production Multi-Agent Architecture for University Viva Presentation & Defense

🎓 Viva Defense Cheat Sheet — 5-Agent Technical Justification

Use these exact bullet points to answer questions from professors during the examination

1. Intake Agent AGENT 1

Code: /backend/app/agents/intake_agent.py

Why separate? Unstructured job data arrives in multiple formats (images, URLs, text, WhatsApp screenshots). A dedicated intake agent decouples dirty parsing logic from risk assessment.

  • OCR Engine: Pytesseract extracts text from noisy flyers.
  • Scraper: BeautifulSoup pulls live recruitment site content.
  • Language ID: Unicode script-block analysis (EN, SI, TA, HI, BN).
  • Output: Normalized JSON with extracted emails, phones & URLs.

2. Linguistic Risk Agent AGENT 2

Code: /backend/app/agents/linguistic_risk_agent.py

Why separate? Psychological manipulation (urgency, upfront money demands) is distinct from website hosting technicalities. It isolates text-level semantics.

  • EMSCAD Benchmark: Trained on 17,880 verified job postings.
  • Payment Flags: Registration fee, laptop deposit, processing fee.
  • Urgency Tactics: "Offer expires in 2 hours", "Instant spot selection".
  • Domain Mismatch: Flagging claims of Google using free @gmail.com.

3. Verification Agent AGENT 3

Code: /backend/app/agents/verification_agent.py

Why separate? Grounding truth in reality. LLMs hallucinate, but live internet registry infrastructure data provides zero-hallucination deterministic truth.

  • WHOIS Lookup: APILayer API checks creation age (<90d = High Risk).
  • Google Safe Browsing: Queries live threat lists for phishing/malware.
  • TLD Screening: Flags shady disposable domains (.xyz, .top, .site).
  • Output: Verification Trust Score & Infrastructure Audit.

4. Reasoning Agent AGENT 4

Code: /backend/app/agents/reasoning_agent.py

Why separate? Core brain. Synthesizes conflicting multi-agent telemetry (e.g. good grammar from Agent 2, but brand-new fraudulent domain from Agent 3).

  • XAI (Explainable AI): Transparent rationale instead of black-box.
  • Score: 0–100 Scam Probability Score & Confidence calculation.
  • Dimensional Sub-scores: Finance, Impersonation, Domain, Urgency.
  • Fact Isolation: Explicitly separates verified facts from inferences.

5. Recommendation Agent AGENT 5

Code: /backend/app/agents/recommendation_agent.py

Why separate? Detection alone does not protect students. Concrete, defensive countermeasures convert passive alerts into active student protection.

  • Contextual Advice: Targets exact detected risks (e.g., fee name).
  • Identity Defense: Warns against sharing National ID (NIC) / bank info.
  • Escalation: Contacts for University Career Units & Cyber Helplines.
  • Localization: Delivers guidance in 5 native regional languages.

Viva Core Pitch (60 Seconds) KEY SUMMARY

"SafeHire does not rely on a single prompt or black-box classifier. Instead, it utilizes an autonomous 5-Agent sequential pipeline where each agent enriches the payload: from multi-modal OCR ingestion (Agent 1), through linguistic scam mining (Agent 2), deterministic WHOIS and Google Safe Browsing infrastructure verification (Agent 3), explainable AI score synthesis (Agent 4), to actionable student protective advice (Agent 5). This architecture eliminates hallucinations, guarantees traceability, and provides defensible evidence for every decision."
